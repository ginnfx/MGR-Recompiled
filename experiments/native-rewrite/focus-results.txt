Instrumentation refinement AFTER these samples: separates submit/present
queue-lock acquisition from the remaining host call time. That refinement is
used by subsequent resolve comparisons. It was not retrospectively measured.

Hypotheses needing the missing focus comparison: OS presentation/composition,
queue contention between host UI and guest GPU submission, or differences in
input/event scheduling. Input polling appears too small to explain10 FPS in
these focused runs; this does not exclude unmeasured OS/cursor event overhead.
Guest and HUD host FPS differ, demonstrating that guest FPS alone is not a
displayed-frame metric. A genuine faster-rendering claim requires matched GPU
execution and workload/scene evidence. No such focus claim is made here.
